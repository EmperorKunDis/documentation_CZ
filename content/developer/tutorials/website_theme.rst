=====================
Vytvořte webový šablonu
=====================

|Pro tento projekt budeme spolupracovat na vytvoření šablony webu plně integrované s Odoo.
Naše klientka společnost Airproof poskytla nejnovější návrh svého voděodolného dronu pro elektronický obchod.
A tento model budeme napodobovat.

Nejprve musíte mít nainstalované Odoo lokálně: doc:instalace Odoa místně
Budete potřebovat také nějaké znalosti v:

- XML
- JavaScript (není nutný)
- Bootstrap 5.1.3
- SCSS
- QWeb (vlastní šablonovací systém Odoa)
- OWL (javascriptový rámec, není povinný)

| **Góly**
| Napodobte design Airproof.
