... atribut:: neviditelný
:noindex:

Zda je prvek viditelný („False“) nebo skrytý („True“), jako v Pythonu.
hodnotí na logickou hodnotu.

....... poznámka::
Existují dvě možnosti použití atributu „neviditelné“:

      - Uživatelská přívětivost: aby se nepřetížila obrazovka a aby bylo pro uživatele snadnější číst.
podle obsahu.
      - Technické: pole musí být v pohledu, který se má použít
Pythonová výrazová struktura.

...... příklad::

... kódový blok::xml


<skupina skrytá="fname_c nebude 4">
<pole název="jméno_c" />
<field name="jmeno_d" />
<skupina>
