.. atribut:: povinný
:noindex:

Zda pole může být prázdné („False“) nebo musí být vyplněné („True“), jako výraz v Pythonu
která hodnotí na booleovou hodnotu.

...... příklad::
... kódový blok::xml

<požadované pole s názvem "jméno_a">
<položka jméno_b povinné="jméno_c ne== 3"/>

:volitelné
:typ: :ref:`Pythonový výraz <reference/view_architectures/python_expression>`
:výchozí hodnota: „Pravda“
