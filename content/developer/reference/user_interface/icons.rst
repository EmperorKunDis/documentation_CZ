========
Ikony uživatelského rozhraní
========

Uživatelské rozhraní Odoa se většinou spoléhá na ikonky FontAwesome4 <https://fontawesome.com/v4/icons/>.

Chybějící ikonografie pro konkrétní funkce jsme nahradili vlastním návrhem
ikony: Odoo UI ikony a ikony tabulkového procesoru.
<ui/odoo-spreadsheet-icons>.

Adaptace RTL
---------------

Směrové ikony mají adaptace s označením „RTL (zleva doprava)“, které ikonu otočí o 180 stupňů.
když je vybrána orientace zleva doprava (RTL).
