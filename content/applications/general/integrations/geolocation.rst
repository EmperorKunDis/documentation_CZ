===========
Geolokace
===========

V Odoo můžete najít kontakty nebo místa a vytvářet trasy na mapě.

.. obrázek: geolokace/kontakty.png
:alt:Mapa zobrazující polohu kontaktu.

Chcete-li tuto funkci používat, otevřete aplikaci „Nastavení“ a v seznamu „Spojení“
sekci, aktivovat: guilabel:„Geolokalizace“. Poté vyberte mezi použitím OpenStreetMap nebo
Google Places API.

**OpenStreetMap**

OpenStreetMap je volně dostupná, otevřená databáze geografických informací, kterou aktualizují a udržují dobrovolníci.
vyberte: guilabel:"OpenStreetMap".

.. důležité::
OpenStreetMap nemusí být vždy přesný. Můžete se „připojit k komunitě OpenStreetMap“.
<https://www.openstreetmap.org/fixthemap>_ a opravit všechny problémy, které se objevily.

**Mapa Google Places API**

Mapa služby Google Places API poskytuje podrobné informace o místech, firmách a zajímavých místech.
podporuje funkce založené na lokalitách jako vyhledávání, navigace a doporučení.

.. důležité::
Používání služby Google Places API může vyžadovat „platbu Googlu
<https://mapsplatform.google.com/pricing/>`.

Pro použití vyberte „Mapa Google Places“ a zadejte svůj API klíč.
<adresa_automatického_vyplnění/generovat_klíč_API>.
