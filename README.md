# Dokumentace k Odoo

## Sestavte dokumentaci místně

### Požadavky

- Git
- Python 3.6, 3.7 nebo 3.8
- Pythonové závislosti uvedené v souboru „requirements.txt“.
- Vytvoř
- lokální kopii [odoo/odoo repozitáře](https://github.com/odoo/odoo) (volitelně)
- lokální kopii repozitáře [odoo/upgrade-util](https://github.com/odoo/upgrade-util) (volitelně).

### Návod

1. V terminálu přejděte do kořenového adresáře dokumentace a spusťte „make“.
Pomocí příkazu make help jsou k dispozici další příkazy.
2. Otevřete soubor „documentation/_build/html/index.html“ v prohlížeči.
3. Podívejte se na tento návod [k dokumentaci](https://www.odoo.com/documentation/latest/contributing/documentation.html).
pro podrobnější pokyny.

Volitelně: umístěte svou místní kopii repozitářů „odoo/odoo“ a „odoo/upgrade-util“ do
do adresáře rodičovského nebo do kořenového adresáře dokumentace, kde se budou stavět
s dokumentovanými Pythonovskými popisky.

## Přispějte do dokumentace

Pro přispění k obsahu dokumentace se obraťte na
[Návod pro přispěvatele](https://www.odoo.com/documentation/latest/contributions/documentation.html).

Pro nahlášení problému s obsahem, požadování nového obsahu nebo pro dotaz použijte
[problém sledování v repozitáři](https://github.com/odoo/documentation/issues).
